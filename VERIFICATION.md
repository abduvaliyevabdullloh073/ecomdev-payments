# Результаты проверки

Проверка выполнена в Linux, Python 3.12.14, Node.js 24.19.0, Chromium 153.0.8010.0.

| Проверка | Результат |
| --- | --- |
| Установка `requirements-dev.txt` в новое пустое виртуальное окружение | Успешно |
| `python -m pytest -q` в новом окружении | **88 passed**, без предупреждений |
| `python -m ruff check .` | All checks passed |
| `python -m ruff format --check .` | Все Python-файлы отформатированы |
| `node scripts/browser-test.mjs` с отдельной временной БД | **10 browser checks passed** |
| Неперехваченные JavaScript-ошибки | Не обнаружены |
| Просмотр снимков интерфейса | Десктоп 1440 px и телефон 390 px; горизонтального переполнения также нет на 320 px |

Браузерные проверки: пустая база, создание и изменение ученика, безопасное отображение HTML в имени, валидация и добавление оплаты, защита от двойной отправки, история, закрытие долга, выбор месяца, поиск и мобильные формы, удаление с платежами, восстановление после сетевой ошибки.

Для проверки браузера в этой среде использован отдельно установленный Chromium через переменную `BROWSER_EXECUTABLE`; стандартная загрузка браузера с CDN Playwright была недоступна. В README приведён обычный путь установки Playwright и Chromium.

Windows и Docker в этой Linux-среде не запускались. Для сдачи рекомендуется основной, проверенный путь через Python; команды для Windows используют интерпретатор виртуального окружения напрямую без изменения политики PowerShell.

Тестовые данные вымышленные. Рабочая база в исходный код не включена; автоматические проверки используют временные базы.
