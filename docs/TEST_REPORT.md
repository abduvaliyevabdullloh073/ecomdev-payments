Для браузерных тестов в этой среде использован установленный отдельно Chromium через `CHROMIUM_EXECUTABLE_PATH`; `CHROMIUM_ARGS` позволяет задать массив параметров запуска в JSON. При обычном запуске без этих переменных Playwright использует браузер из `npx playwright install chromium`. Мобильная проверка — эмуляция размера экрана и сенсорного ввода в Chromium, не запуск Safari на физическом iPhone.

API-тесты проверяют пустую БД, автоматическую миграцию, CRUD, PATCH/PUT, изоляцию платежей учеников, частичную оплату, полную оплату, переплату, нулевой тариф, отсутствие оплат, соседние месяцы, високосный февраль, декабрь/январь, максимальный год, точность 0.1 + 0.2, неверные даты/суммы/ID, ошибки JSON и Content-Type, лимит тела, связанные SQL-параметры, Origin, внешние ключи, каскадное удаление и повторное открытие SQLite-файла.

Все тесты используют изолированные данные. Проверки Windows и удалённый запуск GitHub Actions в этой среде не выполнялись; команды локального запуска не зависят от bash.

Обновление i18n: каталог проверен на заполненность и одинаковые параметры во всех языках; API — на региональные/взвешенные Accept-Language, язык деталей валидации и изоляцию параллельных запросов. Русская и английская страницы дополнительно просмотрены при 1440 px и 390 px, включая мобильный диалог.

Оформление Ecomdev: заменены логотип, favicon, заголовки трёх языков и фирменные цвета. После изменения бренда прошли 28 тестов домена/API/i18n, production-сборка и 18 браузерных тестов. Новый дизайн просмотрен при 1440 px, 1024 px и 390 px; логотип помещается, горизонтального переполнения и ошибок JavaScript нет.
