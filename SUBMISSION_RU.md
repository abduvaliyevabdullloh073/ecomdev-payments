## Рассказ об ИИ — 7 предложений для сообщения в Telegram

В работе использован ChatGPT в режиме Codex: он помог разобрать требования, выбрать Python/FastAPI/SQLite и создать проект с адаптивной веб-страницей.
Лучший результат дали подсказки с конкретными условиями: «хранить деньги целыми тийинами», «учитывать платежи только внутри выбранного месяца» и «проверить учеников без платежей, частичную оплату, переплату и границы месяца».
ИИ сгенерировал исходный код API, SQL-схему, интерфейс, автоматические тесты и документацию; самостоятельно написанного кандидатом программного кода в этой версии нет.
При проверке первоначального варианта была обнаружена потенциальная ошибка: умножение длинной дроби в Decimal могло округлить лишние знаки до проверки точности суммы.
Проверку заменили сравнением исходного значения с его округлением до двух знаков и добавили регрессионный тест с длинной дробью.
В среде Codex были выполнены тесты API, точности расчётов, сохранности данных и параллельных платежей, а также проверки пользовательских сценариев в Chromium на большом и мобильных экранах.
Использование ИИ указано открыто, а принятые ограничения расчёта и план дальнейших улучшений описаны в README.

## Как объяснить решение на интервью

- **Где хранятся данные?** В SQLite, в таблицах `students` и `payments`; платёж ссылается на ученика внешним ключом.
- **Как считается долг?** Из тарифа ученика вычитается сумма его платежей между первым и последним днями выбранного месяца. Если результат положительный, ученик входит в список.
- **Почему LEFT JOIN?** Чтобы не потерять учеников, у которых нет ни одного платежа. Условие даты находится в `ON`, а не в `WHERE`.
- **Почему без float?** В базе лежат целые тийины, а при приёме и выдаче сумм используется `Decimal`: так дробные суммы не создают фиктивную задолженность.
- **Что делает переплата?** Убирает ученика из должников в этом месяце. Перенос на следующий месяц не реализован, поскольку в задании описан помесячный отчёт, а не накопленный баланс.
- **Что произойдёт после изменения тарифа?** Отчёты за прошлые месяцы тоже используют новый тариф. Для неизменных исторических начислений нужна история тарифов.
- **Что происходит при удалении?** SQLite удаляет ученика и связанные платежи одной транзакцией благодаря `ON DELETE CASCADE`; в интерфейсе есть подтверждение.
- **Как проверить?** Команда `python -m pytest -q` проверяет API и расчёты, `npm run test:e2e` — действия в настоящем браузере с временной БД.
